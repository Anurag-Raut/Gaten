## Slang supplement (Living Japanese Slang)

Appended to the same `jmdict.sqlite` by `tools/build_slang_db.py` (Python 3 stdlib only, re-runnable — it drops its previous rows first). Fills the daily-slang gap JMdict leaves (streaming chat, otaku speech, net slang); every row carries `pos = 'slang (Living Japanese)'` and `common = 0`, so JMdict matches still rank above it in the F3 lookup.
