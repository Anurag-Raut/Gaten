Onboarding entrance motion — measured on device
==============================================

Device   AVD Gaten_Heading_Evidence, emulator-5558, Android 14, 1080x2340 @ 440 dpi (392 dp)
Build    app-x86_64-debug.apk, JS from Metro on port 8088 (served bundle grepped for this
         branch's copy before capture: trimmed sentences present, old sentences absent)
Capture  adb shell screenrecord --bit-rate 16000000 (native 1080x2340), frames extracted with
         ffmpeg -fps_mode passthrough. screenrecord is variable-rate: it emits ~60 fps while the
         screen changes and one frame while it is still, so the 260 ms entrance is captured as
         ~16-20 frames at ~16.7 ms each.

How alpha/dy were measured
--------------------------
Each frame's artwork region (x 271..862, y 515..912) was fitted against the settled frame with the
model   frame = alpha * shift(settled, dy) + background,   mask = settled > 15% of max.
alpha is the artwork's opacity; dy is how far below its settled place the artwork sits.
The implemented animation is opacity 0->1 with translateY = (1 - value) * 10 dp, so a correct
capture must satisfy  dy_dp ~= (1 - alpha) * 10.
