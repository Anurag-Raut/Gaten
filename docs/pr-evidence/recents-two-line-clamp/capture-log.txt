```
$ hermesc -b -dump-bytecode <bundle> > <bundle>.hbc.txt     # 592,670 lines each
$ diff bx.hbc.txt ax.hbc.txt | wc -l
14
```

The 14 diff lines are the HBC source hash plus, inside `RecentLookupRow`'s gloss `<Text>`, one extra
constant entry in the props object literal — `PutOwnBySlotIdx r7, r11, 0` / `r7, r10, 1` become
`1` / `2` — i.e. `numberOfLines={2}` really is in the shipped head bytecode and really is absent from
the base one. The string `numberOfLines` is deduplicated in the Hermes string table, so it does not
appear as a new string.
