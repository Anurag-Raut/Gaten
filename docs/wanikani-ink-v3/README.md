# Gaten WaniKani Hub — borderless Ink V3

Open `index.html` in any browser. Choose one of 14 states, Light/Dark, and accent. Screenshots in `/screenshots` were captured from this exact HTML using Chromium. `IMPLEMENTATION_AGENT_PROMPT.md` is the handoff for the coding agent. `STATE_MATRIX.md` defines display/data behavior.

Design changes: Removed the summary/synced text under the subtitle. Replaced outer cards with two editorial hairline-separated modules, with right-hand detail columns and neutral CTAs. Completion uses calm positive labels; unknown data is never rendered as zero.
